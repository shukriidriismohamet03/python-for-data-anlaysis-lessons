# 🐍 Python for Data Analysis Lessons

This repository contains lessons and practice materials for learning **Python for Data Analysis**.

The course covers Python fundamentals, NumPy, and Pandas. It focuses on the basic skills needed to import, explore, clean, transform, summarize, and analyze data using Python and Google Colab.

## 📚 Course Outline

### Python Fundamentals, NumPy & Introduction to Pandas

1. Introduction to Python for Data Analysis
2. Python Fundamentals for Data Analysts
3. NumPy Fundamentals for Data Analysis
4. Introduction to Pandas
5. Importing and Exploring Data

### Data Cleaning, Transformation & Analysis with Pandas

1. Selecting, Filtering and Sorting Data
2. Data Cleaning with Pandas
3. Creating and Transforming Variables
4. Grouping and Summarizing Data
5. Pivot Tables with Pandas
6. Combining Datasets with Pandas
7. Exporting Data and Results

## 🐍 What is Python?

Python is a high-level programming language that is widely used for:

* Software development
* Automation
* Data analysis
* Artificial Intelligence
* Machine Learning
* Scientific computing

Python was created by **Guido van Rossum** and was first released in **1991**.

Python is popular because it is simple, readable, and beginner-friendly.
